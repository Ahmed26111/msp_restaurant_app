## 📱 Overview

**MSP Restaurant App** is a modern Flutter application that provides a seamless food ordering experience. Users can browse meals, view details, add items to cart, and complete payment through an intuitive and responsive UI.

---

## 🌐 API Integration

This app uses a public food API to fetch real data:

🔗 Base URL:
https://free-food-menus-api-two.vercel.app/

### 📌 Example Endpoints:

* `/burgers`
* `/pizzas`
* `/ice-cream`

---

## ✨ Features

### 🚀 Splash Screen

* Smooth entry experience when launching the app

---

### 🧭 Layout Screen

* Bottom Navigation Bar
* Navigate between:

    * 🏠 Home
    * 🛒 Cart

---

### 🍔 Home Screen

* Horizontal categories:

    * All
    * Burgers
    * Ice Cream
    * Pizzas

* Food Cards include:

    * Image
    * Name
    * Country
    * Rating ⭐

👉 Tap on a card → Navigate to Details Screen

---

### 📄 Details Screen

* Full product info:

    * Image
    * Name
    * Rating ⭐
    * Description
    * Price 💰
* Add to Cart functionality

---

### 🛒 Cart Screen

* View selected items
* Remove items ❌
* Checkout button
* 👉 Clicking Checkout → Navigates to Payment Screen
---

### 💳 Payment Screen

* Payment methods:

    * Cash
    * MasterCard
    * Visa

* Shows total price

* Pay button

✅ Displays success dialog after payment

---

## 🛠️ Tech Stack

Splash → Home → Details → Cart → Payment → Success ✅
